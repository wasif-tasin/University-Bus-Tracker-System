# 🚌 University Bus Tracker System

A desktop-based **University Bus Tracker System** developed using **C++** and **SFML 3.1**. This project was developed as a university group project to simulate a real-time university transportation management system with separate **Admin** and **User** functionalities.

---

## 📖 Project Overview

The University Bus Tracker System is a GUI-based desktop application that helps manage university buses, users, and transportation information. The project is built using **Object-Oriented Programming (OOP)** principles in **C++** with the **SFML** graphics library.

The system provides separate interfaces for administrators and users. Administrators can manage buses and university information, while users can log in, view bus details, and track transportation-related information.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/wasif-tasin/University-Bus-Tracker-System.git
```

### 2. Open the Project

Open the project using:

- Visual Studio Code
- Code::Blocks
- Visual Studio
- Or any C++ IDE

### 3. Configure SFML

Make sure **SFML 3.1** is installed and properly configured.

### 4. Build the Project

Compile all source files using your preferred compiler.

### 5. Run

Run the generated executable.

> **Note:** Keep the required SFML DLL files in the executable directory before running the application.
